{% if get_locale() == 'ar' %}حول Marine Waste Tracker{% else %}About Marine Waste Tracker{% endif %}

{% if get_locale() == 'ar' %} منصة مجتمعية علمية لرصد نفايات البحر الأبيض المتوسط {% else %} A citizen-science platform for Mediterranean marine litter monitoring {% endif %}

{% if get_locale() == 'ar' %}🎯 المهمة{% else %}🎯 Mission{% endif %}

{% if get_locale() == 'ar' %} يهدف Marine Waste Tracker إلى تمكين المواطنين والباحثين والمنظمات البيئية من الإبلاغ عن النفايات البحرية وتوثيقها علمياً وفق معايير MSFD/OSPAR، مما يتيح بناء قاعدة بيانات مفتوحة حقيقية تدعم اتخاذ القرار البيئي في منطقة البحر الأبيض المتوسط. {% else %} Marine Waste Tracker enables citizens, researchers, and environmental organisations to report and scientifically document marine litter using MSFD/OSPAR standard categories, building an open dataset that supports environmental decision-making across the Mediterranean basin. {% endif %}

{% if get_locale() == 'ar' %}👥 من يمكنه الاستخدام؟{% else %}👥 Who can use it?{% endif %}

  • {% if get_locale() == 'ar' %}المواطنون{% else %}Citizens{% endif %} — {% if get_locale() == 'ar' %}أبلغ عن أي نفايات تراها على الشاطئ أو في البحر{% else %}Report any litter you see at the beach or on the water{% endif %}
  • {% if get_locale() == 'ar' %}الباحثون{% else %}Researchers{% endif %} — {% if get_locale() == 'ar' %}استخدم فئات MSFD القياسية وصدّر البيانات بصيغة CSV{% else %}Use MSFD standard categories and export data as CSV{% endif %}
  • {% if get_locale() == 'ar' %}المنظمات غير الحكومية{% else %}NGOs{% endif %} — {% if get_locale() == 'ar' %}دعّم حملات التنظيف بتوثيق المواقع وتتبع التحسن{% else %}Document cleanup sites and track improvement over time{% endif %}
  • {% if get_locale() == 'ar' %}ضباط الموانئ والغواصون{% else %}Port officers & divers{% endif %} — {% if get_locale() == 'ar' %}أبلغ عن التلوث في المناطق غير الساحلية{% else %}Report pollution in non-coastal areas{% endif %}

{% if get_locale() == 'ar' %}🔬 المنهجية{% else %}🔬 Methodology{% endif %}

{% if get_locale() == 'ar' %} تعتمد المنصة على تصنيف MSFD (إطار استراتيجية البيئة البحرية للاتحاد الأوروبي) الذي يحدد 12 فئة رئيسية من النفايات البحرية، مما يضمن توافق البيانات مع المعايير الدولية للرصد البيئي. تمر كل ملاحظة بمرحلة مراجعة إدارية قبل ظهورها على الخريطة العامة. {% else %} The platform uses the MSFD (EU Marine Strategy Framework Directive) 12-category waste classification, ensuring data compatibility with international marine monitoring standards. Every observation is reviewed by a moderator before appearing on the public map. {% endif %}

  • {% if get_locale() == 'ar' %}12 فئة MSFD قياسية{% else %}12 MSFD standard waste categories{% endif %}
  • {% if get_locale() == 'ar' %}6 مستويات تقدير للكمية{% else %}6 quantity estimate levels{% endif %}
  • {% if get_locale() == 'ar' %}4 درجات خطورة (منخفض — حرج){% else %}4 severity levels (low — critical){% endif %}
  • {% if get_locale() == 'ar' %}6 أنواع بيئية{% else %}6 environment types{% endif %}
  • {% if get_locale() == 'ar' %}إحداثيات GPS دقيقة{% else %}GPS-accurate coordinates{% endif %}
